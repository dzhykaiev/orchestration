# Projects API

Projects are the core entity. Each project represents a single orchestration goal.

## Create Project

```http
POST /api/projects
Content-Type: application/json

{
  "name": "Todo API",
  "goal": "Build a REST API for a todo list with PostgreSQL storage",
  "mode": "greenfield",
  "llmProvider": "claude",
  "workspaceId": "uuid" // optional
}
```

**Response** `201`:
```json
{
  "id": "uuid",
  "name": "Todo API",
  "goal": "Build a REST API for a todo list with PostgreSQL storage",
  "status": "draft",
  "mode": "greenfield",
  "llmProvider": "claude",
  "costUsd": "0.00",
  "createdAt": "2026-03-31T10:00:00Z",
  "updatedAt": "2026-03-31T10:00:00Z"
}
```

## List Projects

```http
GET /api/projects
GET /api/projects?status=in_progress
GET /api/projects?workspaceId=uuid
```

## Get Project

```http
GET /api/projects/:id
```

Returns project with workstream summary and cost breakdown.

## List Project Issues

Returns issue tickets (bug-type board items) reported from this project.

```http
GET /api/projects/:id/issues
GET /api/projects/:id/issues?status=todo
GET /api/projects/:id/issues?limit=50&offset=0
```

## Start Planning

Triggers the orchestration pipeline. Enqueues a planning job to BullMQ.

```http
POST /api/projects/:id/plan
```

**Response** `200`:
```json
{
  "message": "Planning started",
  "projectId": "uuid"
}
```

This is the key action that kicks off the full orchestration flow:
1. Project status → `planning`
2. Architect agent analyzes the goal
3. Workstreams created
4. Implementation agents start working
5. QA validates output

## Browse Files

```http
GET /api/projects/:id/files
GET /api/projects/:id/files?path=src/routes
```

Returns the file tree generated by agents for this project.

## Project Statuses

```
draft → planning → in_progress → completed
                                → failed
                 → cancelled
         → archived
```

| Status | Description |
|--------|-------------|
| `draft` | Created, not yet started |
| `planning` | Architect agent is working |
| `in_progress` | Implementation agents are working |
| `completed` | All workstreams finished successfully |
| `failed` | One or more critical workstreams failed |
| `cancelled` | Manually cancelled by user |
| `archived` | Archived for record-keeping |
